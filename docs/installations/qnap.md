# 威联通（QNAP）安装

威联通使用的固件为 `ova` 版本，在[下载页](/download)下载对应的 `ova` 固件即可。

## 操作步骤

> 图片来源：[图文教程：威联通安装 Home Assistant OS 极速版](https://mp.weixin.qq.com/s/OSGU-JnSCqRJ3obT2hAGnw)

1. 在[下载页](/download)下载对应的 `ova` 固件

![下载固件](./images/qnap/01.png)

2. 打开威联通的虚拟机工作站，点击新建虚拟机

![新建虚拟机](./images/qnap/02.png)

3. 按照提示步骤操作

![新建虚拟机 2](./images/qnap/03.png)

![新建虚拟机 3](./images/qnap/04.png)

![新建虚拟机 4](./images/qnap/05.png)

![新建虚拟机 5](./images/qnap/06.png)

4. 导入下载好的 `ova` 固件并完成配置

![导入固件](./images/qnap/07.png)

![配置 1](./images/qnap/08.png)

![配置 2](./images/qnap/09.png)

![配置 3](./images/qnap/10.png)

![配置 4](./images/qnap/11.png)

![配置 5](./images/qnap/12.png)

5. 启动虚拟机，等待初始化完成后即可访问

![初始化完成](./images/qnap/13.png)
