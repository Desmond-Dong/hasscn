最近，Home Assistant 开始支持为 integrations 显示 images 和 icons，以在前端中显示。它们看起来很棒，并为 Home Assistant 的 UI 增添了一些色彩。

最近我们收到了很多问题，关于 custom integrations（也称为 custom components）如何添加它们的 images。从今天起，这是可能的！

![HACS icon 在 Home Assistant 前端中的显示](/img/en/blog/2020-05-logos-custom-integrations/customlogo.png)

创建了 custom integration？想让你的 integration 的 logo 和 icon 显示在 Home Assistant 前端中？如果是这样，请访问我们的 [GitHub brands 仓库](https://github.com/home-assistant/brands) 添加你的！

_PS：你知道你也可以将你的 custom integration 添加到我们的 [Python wheels 仓库](https://github.com/home-assistant/wheels-custom-integrations) 吗？这将使你的 custom integration 在 Home Assistant 中的安装变得超快！_
