title: "数据库 schema v32 更新"
---

对于 Home Assistant Core 2023.2，数据库 schema 已更改。

此变更影响那些不通过 `recorder` 的 [`history`](https://github.com/home-assistant/core/blob/dev/homeassistant/components/recorder/history.py) API，而是直接访问 `last_updated`、`last_changed` 或 `time_fired` 列的自定义集成。

[`events`](https://data.home-assistant.io/docs/events) 和 [`states`](https://data.home-assistant.io/docs/events/) 的文档已更新，可在 [Data Science Portal](https://data.home-assistant.io/) 上查阅。
