title: "添加更多单位枚举器"
---

从 Home Assistant Core 2023.1 开始，以下单位常量已弃用，并由相应的 enum 替代：

  - `UnitOfApparentPower` 枚举器替代 `POWER_VOLT_AMPERE` 常量
  - `UnitOfDataRate` 枚举器替代 `DATA_RATE_***` 常量
  - `UnitOfElectricCurrent` 枚举器替代 `ELECTRIC_CURRENT_***` 常量
  - `UnitOfElectricPotential` 枚举器替代 `ELECTRIC_POTENTIAL_***` 常量
  - `UnitOfFrequency` 枚举器替代 `FREQUENCY_***` 常量
  - `UnitOfInformation` 枚举器替代 `DATA_***` 常量
  - `UnitOfIrradiance` 枚举器替代 `IRRADIATION_***` 常量
  - `UnitOfSoundPressure` 枚举器替代 `SOUND_PRESSURE_***` 常量
  - `UnitOfTime` 枚举器替代 `TIME_***` 常量
  - `UnitOfVolumeFlowRate` 枚举器替代 `VOLUME_FLOW_RATE_***` 常量
