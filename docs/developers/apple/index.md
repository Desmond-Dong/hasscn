**Home Assistant Apple 平台 apps** 帮助用户在 Apple 平台上控制并自动化他们的家庭。该项目是开源的、积极维护的，涵盖了主要的 iPhone 和 iPad 应用、Apple Watch、widgets、CarPlay、app extensions 以及支撑服务。

**[查看 GitHub 仓库](https://github.com/home-assistant/iOS)** 以了解当前的代码库和待办工作。

---

## 为什么要贡献？

- **产生影响**：改进将落地到一个被 Home Assistant 用户每天使用的应用中。
- **跨 Apple 平台工作**：在一个仓库中为 iOS、watchOS、widgets、CarPlay、App Intents 和 macOS 打包做出贡献。
- **在实战中学习**：该项目使用包含 Xcode、CocoaPods、Fastlane、GitHub Actions 和自动化测试的真实生产工作流。
- **帮助社区**：更好的文档、更好的 review、更好的 bug 修复都很重要。

---

## 你如何提供帮助

- **代码贡献**：修复 bug、添加功能，或改进平台集成。
- **测试**：在本地验证更改，并帮助捕获各 target 之间的回归。
- **代码 review**：Review pull requests，帮助保持变更小而可维护。
- **文档**：在行为发生变更时，改进贡献者文档和用户可见的配套文档。
- **翻译**：加入[iOS 翻译团队](https://app.lokalise.com/public/834452985a05254348aee2.46389241/)。

---

## 准备好开始了吗？

1. **[查看入门指南](/developers/apple/get_started)** 了解本地设置、签名覆盖以及你的第一次构建。
2. **[阅读架构指南](/developers/apple/architecture)** 以了解仓库的组织方式。
3. **[加入我们的 Discord 社区](https://www.home-assistant.io/join-chat)**，确保选择开发者角色，然后前往 **[iOS](https://discord.com/channels/330944238910963714/1481713628553019392)** 项目线程，与其他贡献者交流。
