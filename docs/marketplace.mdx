# 🛒 应用市场 (Marketplace)

**应用市场**是 Home Assistant 自 **2026.11** 起内置的功能，用于查找并安装社区制作的集成、仪表盘卡片、主题与模板，取代了原来的 HACS。它随 Home Assistant 一同提供，无需额外安装。

功能细节请参阅[官方文档](https://www.home-assistant.io/integrations/marketplace/)，本页只说明**我们这一部分**：面向中国大陆用户的**非官方中继下载源**。

## 下载源

应用市场的目录和你安装的所有内容默认从 GitHub 下载。由于国内访问 GitHub 不稳定，应用市场支持改用**中继**：中继通过一台能访问 GitHub 的服务器转发下载，从而加快国内速度。

可用的下载源：

- **GitHub**：由 GitHub 和 Open Home Foundation 运营，默认选项。
- **非官方中国中继**：由 Home Assistant 中国社区（[hasscn.top](https://hasscn.top)）运营，并以第三方中继作为备用。

:::warning 重要

使用中继作为下载源时，应用市场下载的所有内容都会经过中继的运营方，包括其回退使用的第三方中继在内——无论是目录还是你安装的内容。请只选择你信任的下载源。

:::

:::tip 共享 Token 池

使用中继服务**不需要你提供任何 GitHub Token**。全国所有用户通过中继下载应用市场中的资源时，统一使用社区**共享 Token 池**中的用量，个人无需自行配置 Token 即可使用。

为了让这项本土服务持续稳定地运行下去，欢迎有心的朋友前往 [Marketplace 服务](https://hamrelay.hasscn.top/) 共享你的 Token，为全国用户出一份力。

:::

:::note 合规说明

为符合法规要求，不符合法规的内容将不予中继。

:::

## 切换到中国中继

1. 进入 **设置** → **应用市场**
2. 点击右上角的三个点菜单，选择**下载源**
3. 选择**非官方中国中继**，然后点击**提交**

应用市场会立即以新的下载源重启。

### 出现修复项提示时

如果应用市场无法访问目录，而你所在地区有可用的中继，会出现修复项建议使用中继。你可以在修复项中直接切换到中继，也可以继续使用 GitHub——如果选择继续使用 GitHub，应用市场将不再提示该中继。

### 从 HACS-China 迁移

如果你之前使用的是 [HACS-China](https://github.com/hacs-china)，从老版本更新到 `2026.11.x`（以及后面的版本）后首次启动 Home Assistant 时，应用市场会**自动**将下载源切换为**非官方中国中继**，其共享池中的 GitHub 令牌会被移除，你自己的 GitHub 连接则会保留。

## 问题反馈

使用中继下载源时遇到问题，欢迎通过页面右上角的微信图标加入群聊反馈；应用市场功能本身的问题，请点击对应仓库页面的**问题反馈**联系项目作者，或查阅[官方文档](https://www.home-assistant.io/integrations/marketplace/)。
