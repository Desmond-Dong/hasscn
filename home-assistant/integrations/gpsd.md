# GPSD

The **GPSD** integration is using the GPS information collected by [gpsd](https://gpsd.gitlab.io/gpsd/index.html) and a GPS receiver.

:::note 配置
此集成可通过 UI 配置。前往 **设置 > 设备与服务** 添加。
:::
