# SiteSage Emonitor

The **SiteSage Emonitor** integration allows local power monitoring on a per circuit basis via an [Emonitor](https://powerhousedynamics.com/solutions/sitesage/) device.

:::note 配置
此集成可通过 UI 配置。前往 **设置 > 设备与服务** 添加。
:::
