# Home Assistant

唤醒你的家

> 将本地控制与隐私放在首位的开源家庭自动化平台，由全球创客与 DIY 爱好者社区共同驱动。

[开始使用](/home-assistant/installation/index) | [集成目录](/home-assistant/integrations/index)

## Features

- 💡 **支持 1000+ 品牌**: Home Assistant 可集成上千种设备与服务，并会自动扫描网络中的已知设备，帮助你快速完成设置。
- 🤖 **强大的自动化**: 接入家中设备后，即可使用高级自动化引擎，让灯光、门库和提醒自动为你工作。
- 🖥️ **灵活的仪表盘**: 仪表盘可自由定制，支持拖放式配置，可在手机和桌面端集中查看与控制智能家居。
- 🎙️ **Assist 语音助手**: 使用自然语言控制 Home Assistant，基于开放语音基础设施，并由社区知识持续完善。
- 🧩 **使用应用扩展系统**: 除了 Home Assistant 本体，你还可以轻松安装其他应用来扩展家庭管理能力。
- 🔒 **数据始终保留在本地**: 设备优先通过本地方式通信，仅在没有其他选择时才回退到云端，而且不会把数据存储在云上。
- ⚡ **家庭能源管理**: 获取能耗洞察，优化太阳能发电与用电计划，帮助你更高效地管理家庭能源并节省费用。
- 📺 **Home Assistant Cast**: 让电视屏幕也成为仪表盘显示终端，把家里的各类屏幕变成智能家居控制面板。
- 🏷️ **NFC 标签**: 通过 NFC 快速触发音乐、场景和日常自动化，把重复操作变得更轻松。
