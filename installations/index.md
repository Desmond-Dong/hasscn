## Features

- [🖥️ **x86 物理机**](/installations/x86): 适合 x86 架构主机，使用 Balena Etcher 烧录安装专用系统到 U 盘，引导安装 Home Assistant。
- [🍓 **树莓派**](/installations/raspberrypi): 适合 Raspberry Pi 3、4、5 用户，使用 Balena Etcher 或 Raspberry Pi Imager 烧录镜像。
- [🏠 **Sonoff iHost**](/installations/ihost): 适合希望在 iHost 上直接启动 Home Assistant 的用户，包含 SD 卡烧录、启动与硬件资源说明。
- [🍊 **香橙派**](/installations/orangepi): 适合 Orange Pi CM4 等设备，包含卡刷参考与 EMMC 写入流程。
- [🐧 **Proxmox VE**](/installations/proxmox): 适合在 PVE 中创建虚拟机部署 Home Assistant，重点覆盖 qcow2 导入与关键虚拟机设置。
- [🐂 **飞牛 fnOS**](/installations/fnos): 适合在飞牛 NAS 的虚拟机中部署 Home Assistant，使用 ova 或 qcow2 固件导入。
- [🖧 **ESXi**](/installations/esxi): 适合在 VMware ESXi 宿主机上部署 Home Assistant，使用 vmdk 或 ova 固件导入。
- [🗄️ **威联通 QNAP**](/installations/qnap): 适合在威联通 NAS 虚拟机工作站中部署 Home Assistant，使用 ova 固件导入。
- [🍏 **UTM（Mac）**](/installations/utm): 适合在 Mac 的 UTM 虚拟机中部署 Home Assistant，使用 qcow2 固件导入。
- [🪟 **Hyper-V**](/installations/hyperv): 适合在 Windows Hyper-V 环境下部署，当前为简版入口，后续可继续补充完整流程。
