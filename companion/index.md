# Companion Apps

您的智能家居移动伴侣

> 随时随地控制智能家居，接收通知，追踪位置，与 Home Assistant 无缝集成

[入门指南](getting_started/) | [核心功能](core/)

## Features

- [📱 **📱 多平台支持**](/companion/getting_started/): 支持 iOS、Android、Apple Watch、Wear OS、Android Auto、CarPlay、Meta Quest 等多平台
- [🔔 **🔔 通知推送**](/companion/notifications/basic): 接收来自 Home Assistant 的实时通知，支持可操作通知、附件、关键通知等多种类型
- [📍 **📍 位置追踪**](/companion/core/location): 自动化基于位置的情景，支持 GPS、WiFi、蓝牙等多种定位方式
- [📊 **📊 传感器集成**](/companion/core/sensors): 将移动设备的传感器数据发送到 Home Assistant，如电池、运动、网络状态等
- [🎛️ **🎛️ 快捷控制**](/companion/integrations/): 支持 Widget、快捷方式、Siri 快捷指令等多种快捷控制方式
- [🏠 **🏠 远程访问**](/companion/getting_started/connection_security_level): 无需 VPN 即可远程访问您的 Home Assistant 实例，随时随地控制智能家居
