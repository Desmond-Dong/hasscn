从 Home Assistant Core 2023.3 开始，部分常量和函数在
`homeassistant.helpers.json` 和 `homeassistant.util.json` 之间进行了移动：

* `save_json` 和 `find_paths_unserializable_data` 函数现在应
  从 `homeassistant.helpers.json` 导入
* `json_loads` 函数现在应从 `homeassistant.util.json` 导入
* `JSON_ENCODE_EXCEPTIONS` 和 `JSON_DECODE_EXCEPTIONS` 常量现在应
  从 `homeassistant.util.json` 导入
