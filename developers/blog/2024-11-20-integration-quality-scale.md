自 2020 年最初的质量等级推出以来，Home Assistant 发生了相当多的变化。
无论是集成的开发方式还是它们能提供的功能都有变化。
然而，质量等级尚未更新以反映这些变化。

在过去的几个月里，我们一直与社区一起制定一套符合 Home Assistant 当前状态的新集成质量等级。
以下是变更概览：

* 质量等级现在分为四个等级：Bronze、Silver、Gold 和 Platinum。新增的 Bronze 等级是今后新 core 集成的最低要求。这虽然暂时略微降低了新集成的门槛，但它可以明确地说明在这个时代对 core 集成有何期望。
* 新增了一个非分级的 legacy 等级，用于那些尚未可通过 UI 配置的集成。该等级会向用户表明，与可通过 UI 配置的集成相比，该集成可能无法满足其预期。
* 为了让该等级体系能够随 Home Assistant 一起发展，并避免未来再次大规模返工，我们为该等级体系设计了一份规则手册，以明确在添加新规则时需要做什么。
* 为了表明项目致力于保持该等级体系的更新，我们创建了一份架构决策记录 (ADR)，描述了保持等级体系更新的目标和流程。
* 开发者文档现在有了[一个全新的章节](/developers/core/integration-quality-scale.md)专门介绍集成质量等级。它包含了每条规则及其背后的理由，并提供了示例以展示如何实现。此外，还有一份[检查清单](/developers/core/integration-quality-scale/checklist.md)可用于更改集成的等级。
* 文档现在也在集成的质量中发挥作用，因为集成的用户体验不仅仅取决于代码。
* 为了追踪集成的进度，我们在集成文件夹中新增了[一个 `quality_scale.yaml` 文件](https://github.com/home-assistant/core/blob/dev/homeassistant/components/airgradient/quality_scale.yaml)。该文件将包含集成所遵守的所有规则列表，以及可能的豁免说明及其原因。

在这一切就绪后，你可能会想知道接下来的步骤是什么。
由于这是对等级体系的一次重大返工，我们决定取消当前集成的等级。
这意味着这些集成需要提交 PR，以将其等级恢复到它们认为应有的水平。

我也希望激励社区帮忙尽可能多地将集成提升到 Bronze（或更高）等级。
我还要感谢社区在质量等级方面的贡献以及他们维护集成所付出的努力。
没有社区，Home Assistant 就不可能像今天这样出色 ❤️。
