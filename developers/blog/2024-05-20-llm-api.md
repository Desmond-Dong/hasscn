自从作为"语音之年"（Year of the Voice）的一部分在 Home Assistant 中引入 LLMs 以来，我们收到了允许 LLMs 与 Home Assistant 交互的请求。现在，通过将 Home Assistant API 暴露给 LLMs，这已成为可能。

Home Assistant 将附带一个内置的 Assist API，该 API 遵循内置的 conversation agent 也可访问的能力和已暴露的 entity。

与 LLMs 交互的集成应更新其集成以支持 LLM API。

自定义集成的作者可以创建自己的 LLM API，为 LLMs 提供更高级的 Home Assistant 访问权限。

更多信息请参阅 [LLM API 文档](/developers/core/llm.md)，以及[此示例 pull request](https://github.com/home-assistant/core/pull/117644)了解如何在您的集成中集成 LLM API。
