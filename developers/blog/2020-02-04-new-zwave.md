在 State of the Union 上，我们[介绍了我们正在开发新的 Z-Wave integration](https://youtu.be/tc17q1Zn0Xs?t=4482)。它基于 Open Z-Wave 项目的一个新项目 [OZWDaemon](https://github.com/OpenZWave/qt-openzwave)，我们将通过 MQTT 与它通信。

这种新方法使我们能够直接与 Open Z-Wave 的核心集成，而无需依赖通过其他语言的 bindings。这使得我们能够轻松保持与最新 Open Z-Wave 版本的同步。

得益于 [@cgarwood] 和 [@marcelveldt] 的努力，integration 取得了很大进展，你可以从今天开始作为 [custom component](https://github.com/cgarwood/homeassistant-zwave_mqtt) 测试它。目前还处于早期阶段，并非所有设备类型都已支持。目前它支持 lights、switches、sensors 和 binary sensors。该 custom component 由新的 [`python-openzwave-mqtt`](https://github.com/cgarwood/python-openzwave-mqtt) 包提供动力。

[请试用。](https://github.com/cgarwood/homeassistant-zwave_mqtt#requirements) 如果你发现任何 bugs，请[创建 issue](https://github.com/cgarwood/homeassistant-zwave_mqtt/issues/new)。如果你使用 Home Assistant 0.105，请使用 topic `openzwave/#` 上的新 `mqtt.dump` service 对 Open Z-Wave 实例进行 dump，并将其附加到你的 issue 中。Dump 将被写入 config 文件夹中的 `mqtt_dump.txt`。

一旦 integration 足够成熟，它将成为 Home Assistant Core 的一部分。

[@cgarwood]: https://github.com/cgarwood

[@marcelveldt]: https://github.com/marcelveldt
