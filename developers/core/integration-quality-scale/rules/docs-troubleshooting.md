## 理由

我们应提供解决常见问题的说明。
在可能的情况下，故障排除主题应包含症状描述以及解决问题所需的步骤。
这能减少支持请求的数量，并改善用户体验。

## 示例实现

```markdown showLineNumbers
## 故障排除

### 无法设置设备

#### 症状："无法访问此设备"

在尝试设置集成时，表单显示消息"无法访问此设备"。

##### 说明

这意味着设备的设置不正确，因为设备需要启用本地通信功能。

##### 解决方法

要解决此问题，请尝试以下步骤：

1. 确保设备已上电（LED 亮起）。
2. 确保设备已连接到互联网：
   - 确保制造商的应用能够看到该设备。
3. 确保设备已启用本地通信：
   - 检查设备的设置。
   - 检查设备的用户手册。
...

### 我看不到我的设备
请确保设备可通过制造商的应用看到并控制。
如果不能，请检查设备的电源和网络连接。

### 设备一天后变为不可用
请确保你已关闭设备的省电模式。
```

## 例外

本规则没有例外。
