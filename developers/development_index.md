Home Assistant 的核心从一开始就被设计为易于通过集成来扩展。在本节中，我们重点关注如何开发集成。

在开始之前，请确保你已阅读了[Home Assistant 整体架构](/developers/architecture_index.md)，以便熟悉构成 Home Assistant 的概念。

如需获取支持或就为 Home Assistant 的开发做贡献提出问题，请加入 [Discord](https://www.home-assistant.io/join-chat/) 上的 **#developers** 频道，或在 **#support** 频道中创建主题。
分配 Developer 角色：在侧边栏中，选择 **Channels & Roles**，然后选择 **I want to contribute dev skills to Home Assistant** 即可获得访问这些频道的权限。
